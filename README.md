# Родословная рода Нарожных

Статический сайт на четырёх языках: RU, UA, EN, DE. Бэкенд не нужен. Откройте `index.html` двойным кликом или выложите папку на GitHub Pages или Netlify.

## Структура

| Путь | Что там |
|---|---|
| `data/people.json` | Люди, связи между ними, статусы, список документов |
| `i18n/ru.json`, `uk.json`, `en.json`, `de.json` | Все тексты: имена, биографии, факты, подписи, разделы |
| `docs/` | Сканы и фотографии |
| `data/bundle.js` | Автоматическая копия данных для открытия двойным кликом. Вручную не редактируется |
| `tools/update-bundle.bat` | Пересобирает `data/bundle.js` |

## Важно после любых правок

На GitHub Pages сайт читает JSON-файлы напрямую. При открытии двойным кликом браузер запрещает читать соседние JSON, поэтому используется `data/bundle.js`.

После правок в `data/` или `i18n/` запустите двойным кликом `tools/update-bundle.bat`. Скрипт также проверит, нет ли ошибок в JSON. Если обновилась только картинка в `docs/`, ничего запускать не нужно.

## Как добавить скан

1. Положите файл в `docs/`, например `docs/1925_zapis.jpg`.
2. Добавьте его в список `documents` в `data/people.json`:

```json
{ "id": "zapis_1925", "file": "docs/1925_zapis.jpg" }
```

3. Добавьте подпись в раздел `docs` каждого файла в `i18n/`:

```json
"zapis_1925": { "title": "Что это за документ", "shelfmark": "ДАХО, ф. 40, оп. 139, спр. 400" }
```

4. Укажите `id` документа у нужного человека в `data/people.json`: `"docs": ["zapis_1925"]`.
5. Запустите `tools/update-bundle.bat`.

Документ сам появится в карточке человека и в общей галерее раздела «Источники».

## Как добавить человека

1. Добавьте запись в `people` в `data/people.json`:

```json
{ "id": "ostap_b", "line": "berezhny", "status": "family" }
```

2. Свяжите его с родными. Например, чтобы Остап стал отцом Николая, допишите Николаю `"father": "ostap_b"`.
3. Добавьте тексты в раздел `people` каждого файла в `i18n/`:

```json
"ostap_b": {
  "name": "Остап Бережной",
  "years": "ок. 1890",
  "place": "Залиман",
  "role": "прапрадед",
  "bio": "Короткая биография.",
  "facts": [
    "Простой факт.",
    { "t": "Факт со своим статусом.", "s": "family" },
    { "t": "Цитата из документа:", "q": "оригинал цитаты", "tr": "перевод" }
  ]
}
```

Если в каком-то языке текста нет, сайт покажет русский вариант. В `ru.json` поле `tr` оставляйте пустым.

4. Запустите `tools/update-bundle.bat`. Древо перестроится само.

### Поля человека в `people.json`

| Поле | Значение |
|---|---|
| `id` | Уникальный код латиницей |
| `line` | Цвет линии: `narozhny`, `orlov`, `teslenko`, `yudkalo`, `berezhny`, `bondarenko` |
| `status` | `confirmed` — документ, `family` — со слов семьи, `probable` — требует проверки |
| `father`, `mother` | `id` родителей |
| `possibleFathers` | Список возможных отцов; связь рисуется пунктиром |
| `uncertainLink` | `true`, если родство с братьями и сёстрами не доказано |
| `spouse` | `id` супруга, если общих детей в данных нет |
| `living` | `true` скрывает всё, кроме имени и родства |
| `docs` | Список `id` документов |
| `story` | Ключ страницы-истории, карточка получит золотую рамку |

## Живые люди

Для живых людей указывайте в `i18n` только `name` и `role`, а в `people.json` ставьте `"living": true`. Сайт скрывает остальное, но JSON-файлы на GitHub Pages открыты всем, поэтому лишних данных в них быть не должно.

## Как вписать имя мамы

В `i18n/*.json` замените `people.mother_t.name` на настоящее имя. Затем удалите `"placeholderName": true` у `mother_t` в `data/people.json` и запустите `tools/update-bundle.bat`.
